# Open source projects

The projects Matt curates on matttrifilo.com/open-source, in the order the
page lists them. Names, descriptions and repository URLs are copied from
content/open-source.ts, the reviewed list that the page renders.

The live page also shows each repository's primary language, star count,
last-push date and homepage, which lib/github.ts fetches from GitHub when
the site is built. Those numbers change between deploys, so they are
deliberately left out of this knowledge base; point people at the page or
at GitHub for current figures.

## decant

- Repository: https://github.com/mtrifilo/decant
- Owner: mtrifilo
- What it is: a CLI to transform your clipboard into markdown for LLM context.

## psychic-homily-web

- Repository: https://github.com/mtrifilo/psychic-homily-web
- Owner: mtrifilo
- What it is: a website to document and amplify new music releases, shows,
  and cultural events from Arizona musicians and beyond.
